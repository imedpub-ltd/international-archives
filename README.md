*International Archives (IA)* is a peer-reviewed, agentic-friendly scientific journal published by **iMedPub** (International Medical Publisher, Crossref Member ID `2155`). It covers multidisciplinary scientific inquiries, high-performance data science, mathematical modeling, bioinformatics, physics, and computable engineering.

---

## 🏛️ Scope & Editorial Pillars
* **Universal Domain-Agnostic Science**: High-rigor empirical and theoretical contributions across all natural, computational, and formal sciences.
* **Computable Papers**: Articles are published alongside executable code capsules (`.capsule.json`) and interactive MCP interfaces.
* **Centaur Peer Review**: Advanced agentic verification coupled with substantive human expert evaluation.
* **Dual-Anchor Certification**: Formal Crossref DOI (`10.3823/ia.YYYY.ID`) interlocked with persistent Zenodo reproduction capsules.

---

## 📋 Submissions
Authors must first deposit an AI-audited preprint in [EdiTxt Preprints](https://preprints.imedpub.org) before submitting for formal peer review.
Submissions are managed entirely through **GitHub Pull Requests** and trackable via GitHub Projects.
